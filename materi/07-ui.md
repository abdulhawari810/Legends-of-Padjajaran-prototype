# 07 — UI: DOM + CSS + Jembatan ke Phaser

> Prasyarat: [03](03-arsitektur.md). Fakta utama: **tidak ada React**.
> UI = `index.html` (423 baris, ±140 id unik) + `src/style.css` (2.390 baris) + 17 modul
> `src/ui/` berpola `init*()`.

## 1. Struktur layar (`index.html`)

```
#auth-screen → login/register + daftar profil
#job-create-screen → pilih class sekali (warrior/mage/archer)
#app
 ├─ #game-container      ← kanvas Phaser disuntik ke sini
 ├─ #ui-overlay (pointer-events: none!)
 │   ├─ #top-hud: #player-frame (avatar+Lv+HP/MP/EXP+gold) + #target-frame + #top-menu (5 tombol)
 │   ├─ #minimap-wrap > canvas#minimap + N
 │   └─ #bottom-bar: joystick | #job-select (jadi label read-only) | #action-cluster
 │       (interact 💬, potion, 3 skill, ⚔; #quick-slots 3 tombol)
 ├─ panel: char/bag/quest/npc/settings (+ chat & quick-menu khusus desktop)
 ├─ #death-overlay (☠️ + penalti + Respawn)
 └─ #rotate-hint (hanya touch portrait → suruh lanskap)
```

**Jebakan `pointer-events`**: `#ui-overlay` = `none` agar sentuh tembus ke
kanvas; tombol/panel yang butuh klik harus `auto` (lihat `#top-menu`,
`.panel`, `#attack-btn`). Tombol baru tidak bisa diklik? Cek ini dulu.

## 2. Pola `init*()` — setiap modul UI sama bentuknya

```ts
// Contoh: src/ui/attack.ts (16 baris, lengkap!)
import { VirtualInput } from '../game/input/VirtualInput';
export function initAttackButton() {
  const btn = document.getElementById('attack-btn');
  if (!btn) return;                       // guard: elemen boleh tidak ada
  btn.addEventListener('pointerdown', (e) => {
    e.preventDefault();
    VirtualInput.requestAttack();          // tulis antrean, BUKAN panggil game
    btn.classList.add('pressed');
  });
  window.addEventListener('pointerup', () => btn.classList.remove('pressed'));
  btn.addEventListener('contextmenu', (e) => e.preventDefault());
}
```
Urutan: ambil elemen → guard null → pasang listener → dipanggil sekali dari
`app.ts:startGame()`. Semua `init*` (`initJoystick`, `initHud`, `initMinimap`,
`initChat`, …) mengikuti pola ini. `pointerdown` dipakai (bukan `click`)
agar responsif di HP; `pointercancel`/`pointerup` untuk reset.

## 3. Jembatan dua arah UI ↔ Phaser

**UI → game: tulis state / kirim event.**
- Joystick → `VirtualInput.set(x, y)` dibaca tiap frame (`hud.ts` tidak
  pernah import Player/MapScene — buktinya di kode).
- Tombol aksi → `requestAttack()/requestSkill(i)` (antrean 1x pakai).
- Klaim quest, reset map, beli/jual → `dispatchEvent(CustomEvent(...))`
  didengar MapScene via helper `onWin` (auto-lepas saat pindah map).

**Game → UI: event `stats-changed` dkk.**
Contoh lengkap `hud.ts` (29 baris, baca utuh di file): dengar
`CustomEvent<StatsSnapshot>` → hitung persen → set `style.width` +
`textContent`. Panel lain (`charPanel` 437 baris: 4 tab status/ability/quest/
skill; `gamePanels` 654 baris: tas+quest+bounty+achievement+toast) sama polanya,
hanya render lebih kaya.

**Minimap** (`minimap.ts` 46 baris): MapScene kirim `minimap-update` tiap
400ms → gambar ulang titik (portal cyan, NPC kuning, monster merah,
boss ungu, pemain putih + bingkai kamera) di `<canvas>` 2D biasa
(tanpa Phaser!).

## 4. Styling: menemukan & mengubah tampilan

`style.css` berkelompok (lihat nomor baris di katalog subagen UI,
[08](08-file-katalog.md)): base → top-HUD emas → buff → target → minimap →
bottom-bar → media query → quick-menu/chat desktop → panel generik → auth →
char → equipment → toast/quest → responsif akhir → slot/death/settings.

Aturan responsif:
- HP lanskap pendek (`max-height:500px`): semua dipadatkan (tombol 36px,
  minimap 96px).
- Touch portrait → `#rotate-hint` menutup layar (paksa lanskap).
- Desktop (`hover:hover + pointer:fine`): joystick & top-menu sembunyi,
  diganti quick-menu + chat; skill pindah kanan-bawah.

**Latihan bertahap:**
1. Ganti warna `#hp-fill`, rebuild, lihat.
2. Sembunyikan `#gold-row` via CSS, pastikan game tetap jalan.
3. Tambah tombol bisu baru yang dispatch event sendiri (contoh di 09).
**Kriteria:** bisa menemukan file+selector untuk tiap elemen + menjelaskan
alur event bolak-balik.
